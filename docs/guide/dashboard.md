# ダッシュボード

::: warning 今は案内していません
ブラウザで見るダッシュボード（`npx cc-company-dashboard`）は、今は受講者の方に案内していません。
同じネットワーク（同じ Wi-Fi など）にいるほかの人のパソコンからも見えてしまう作りのためです。
:::

組織の状況は、秘書に「**ダッシュボード**」と話しかけると、文字の一覧で確認できます（今までどおり使えます）。

```
> ダッシュボード
秘書:
  秘書室:
    TODO（今日）: 3件 未完了 / 1件 完了
    Inbox: 2件 未整理
```

詳しくは [毎日の使い方](./daily-usage.md) を見てください。
