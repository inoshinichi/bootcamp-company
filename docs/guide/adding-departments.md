# 部署を追加する

bootcamp-company の核心機能です。使っていくうちに、秘書が部署の追加を提案します。

## 秘書からの提案

同じ作業が2回目に来ると、秘書が「手順書づくり」とセットで部署の追加を提案します。空っぽの部署は作りません。

```
> 競合サービスについて調べて
秘書: 承知しました。調べますね。

（数日後...）

> 別の競合も調べて
秘書: 競合の調査が2回目ですね。
      リサーチ部を作って、今回のやり方を「競合調査」の手順書としてそこに置きます。
      次からは「競合調べて」でリサーチ部がこの手順どおりに動きます。作ってよいですか？

あなた: 作って

→ .company/research/ が作られ、manuals/ に手順書が1つ置かれる
```

## 自分から依頼する

もちろん、直接依頼もできます。そのときは、最初に任せる仕事を1つ聞かれ、それが最初の手順書になります。

```
> PM部門を作って
秘書: 作りますね。最初に任せたい仕事を1つ教えてください。
      それをPM部門の最初の手順書にします。

→ .company/pm/ が作られ、manuals/ に手順書が1つ置かれる
```

## 追加される部署の構成

部署が追加されると、以下が自動生成されます：

- **部署フォルダ** — `.company/[department]/`
- **部署の CLAUDE.md** — その部署のルールと振る舞い
- **サブフォルダ** — 部署ごとのファイル管理用
- **テンプレート** — ファイル作成時の雛形

例えば、リサーチ部門を追加すると：

```
.company/
├── CLAUDE.md              ← 部署一覧が更新される
├── secretary/
└── research/              ← 新しく追加
    ├── CLAUDE.md           ← リサーチのルール
    ├── manuals/            ← 手順書
    ├── inbox/              ← 受け取り箱
    └── topics/             ← 調査トピック管理
```

## 利用可能な部署

| 部署 | 担当領域 |
|------|---------|
| PM | プロジェクト進捗、チケット管理 |
| リサーチ | 市場調査、競合分析、技術調査 |
| マーケティング | コンテンツ企画、SNS、キャンペーン |
| 開発 | 技術ドキュメント、設計、デバッグ |
| 経理 | 請求書、経費、売上管理 |
| 営業 | クライアント管理、提案書 |
| クリエイティブ | デザインブリーフ、ブランド管理 |
| 人事 | 採用管理、チーム管理 |

詳細は [部署一覧リファレンス](/reference/departments) を参照してください。
