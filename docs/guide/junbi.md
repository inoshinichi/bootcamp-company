# 研修の前にやっておくこと（準備の紙）

AIブートキャンプ当日に、あなたの秘書（AI）とメール・予定・ファイルをつなぎます。
**当日つまずかないために、次の①〜⑥を前日までにお願いします（⑦〜⑨はできる方・当てはまる方だけ）。** 分からない所は、そのままにして当日お越しください。一緒にやります。

---

## ① Claude のアカウントを作って、有料プランに入る

- https://claude.ai を開き、**お仕事のメールアドレス**でアカウントを作ります
- プラン: 講師から案内したプラン（Pro など）に入ってください
- ⚠️ 当日、秘書（Claude Code）にも**この同じアカウント**でログインします。別のアカウントや「APIキー」でログインすると、つながりません

## ② メールとカレンダーをつなぐボタンを押しておく（Google・Microsoft 365 の方）

お仕事のメールが **Google** か **Microsoft 365** で動いている方は、ボタンを押すだけでつながります。
（どちらか分からない方は、この②は飛ばしてください。当日、秘書がメールアドレスから調べます）

1. https://claude.ai/customize/connectors を開く（https://claude.ai にログインして、左の「カスタマイズ」→「コネクター」。英語で「Customize」→「Connectors」と出ることもあります）
2. **Google の方**: 「Gmail」「Google カレンダー」「Google ドライブ」をそれぞれ押して、会社の Google アカウントでログイン
3. **Microsoft 365 の方**: 「Microsoft 365」を押して、会社のアカウントでログイン
   - 個人の Outlook.com・Hotmail のメールはつなげません（仕事用の Microsoft 365 だけです）
   - 「管理者の承認が必要です」と出たら、**会社の Microsoft の全体管理者（グローバル管理者）の方**（IT 業者・情報システム担当など）に許可をお願いしてください。お願いの文面は、当日秘書が作ることもできます
   - 会社で Claude を **Team / Enterprise プラン**で契約している場合は、Claude の管理者の方が管理画面で Microsoft 365 の連携を有効にしないと、ボタンが出ません

## ③ メールのパスワードが分かるか確かめる（レンタルサーバー・プロバイダのメールの方）

会社のメールを、エックスサーバー・さくら・OCN などのサーバーやプロバイダで使っている方は、**メールのパスワード**が必要です。

- 分からないときは、次の順に探してください
  1. 業者やプロバイダから届いた「ご利用内容のお知らせ」「設定通知書」
  2. メールを設定してくれた人（パソコン業者・社内の担当者）に聞く
- **Yahoo メールの方**: Yahoo メールの「設定」→「IMAP/POP/SMTPアクセス」で、「Yahoo! JAPAN公式サービス以外からのアクセス」を許可します（当日でも大丈夫です）。ログインにパスワードを使っているか、自動転送を使っていないかも見ておいてください（自動転送とは一緒に使えません）
- ⚠️ **パスワードを作り直す（再発行する）のは、当日まで待ってください。** 作り直すと、そのメールを見ているスマホや他のパソコンも全部入れ直しになります。当日、秘書と一緒に確かめてから行います

## ④ パソコンの Outlook の設定を1か所だけ変える（Outlook でプロバイダのメールを受け取っている方）

Outlook が「受け取ったら、サーバーからメールを消す」設定になっていると、秘書がメールを読めません。

- **Windows の Outlook**: 「ファイル」→「アカウント設定」→ 自分のアカウントをダブルクリック →「詳細設定」→「配信」タブ
  → **「サーバーにメッセージのコピーを置く」にチェック** →「サーバーから削除する」に **14日後**
- 前日までに変えておくと、当日には数日分のメールを秘書が読めます
- 分からなければ、当日一緒にやります

## ⑤ 秘書に見せてよいフォルダを1つ決めておく

秘書は、あなたが決めたフォルダの中の資料を読んで仕事をします。
「見積書のフォルダ」「営業資料のフォルダ」など、**見せてよい場所を1つ**決めておいてください（パソコンの中、共有フォルダ、OneDrive・Google ドライブ・Dropbox のどれでも大丈夫です）。

## ⑥ ブラウザに拡張機能「Claude」を入れておく

秘書が、あなたのパソコンのブラウザで管理画面などを開く作業（ログインが要るサイト）に使います。

1. Google Chrome が入っていなければ入れる（おすすめは Chrome です。Chrome を入れられない会社のパソコンでは Microsoft Edge でも使えると Claude Code の公式文書にあります。Edge で動くかは未確認です。スマホでは使えません）
2. Chrome ウェブストアの「Claude」（https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn）を開き「Chrome に追加」
3. 拡張機能を開いて、**①と同じ Claude のアカウント**でログイン
4. 使えるのは Pro・Max・Team・Enterprise のプランです。会社のパソコンで拡張機能を入れられない場合は、そのまま当日お越しください。代わりの道を一緒に考えます

## ⑦ Claude Code 本体を入れておく（できる方だけ）

入れ方は [README の「受講者の方へ：入れ方」](https://github.com/inoshinichi/bootcamp-company#受講者の方へ入れ方) の「2. Claude Code 本体を入れる」です。入れられなかったら、そのまま当日お越しください。一緒に入れます。

あわせて、プラグインを入れるのに使う「Git」も入れておきます（README の同じ所に書いてあります）。

- Windows: PowerShell で `winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements`（入ったら PowerShell を開き直す。質問が出たら `Y`、許可を求める画面が出たら「はい」。出ないこともあります）
- Mac（全員）: ターミナルで `xcode-select --install`（10〜30分。⑧と同じものです。すでに入っていれば「already installed」と出ます）
- `git --version` で番号が出れば準備できています

## ⑧ Mac で「サーバーのメール」か「iPhone のカレンダー」をつなぐ方だけ

Mac の「ターミナル」アプリを開いて `xcode-select --install` と入力し、画面の案内に従ってください（10〜30分かかります）。すでに入っていれば「already installed」と出ます。

## ⑨ Windows で「サーバーのメール」か「iPhone のカレンダー」をつなぐ方だけ

秘書がサーバーのメールなどを読む道具は「Python」というソフトで動きます。Windows には最初から入っていないことが多いので、確かめておきます。

1. スタートボタン →「PowerShell」と入力して開く
2. `py -3 --version` と入力して Enter。`Python 3.` で始まる番号が出れば準備できています
3. 出ないときは、https://www.python.org/downloads/windows/ から Python 3 を入れます（入れる画面で「管理者の権限を使う」には印を付けず、自分だけに入れれば大丈夫です）
4. 会社のパソコンでソフトを入れられないときは、情報システムの担当の方に相談してください。入れられないままでも当日お越しください。メールは「届いたメールを貼り付ける」やり方で先に進められます

### 当日持ってくるもの

- ふだん仕事で使っているパソコン（Windows・Mac どちらでも）
- メールのパスワード（③の方）
- スマホ（ログインの確認コードが届くことがあります）

### よくある質問

- **Q. パソコンの Outlook でメールを見ています。Microsoft 365 ですか？**
  A. 画面が Outlook でも、中身は Google や別のサーバーのことがよくあります。当日、秘書がメールアドレスから調べるので、気にしなくて大丈夫です
- **Q. LINE WORKS・Google Chat を使っています**
  A. 今はまだ秘書と直接つなげません。届いたメッセージを貼れば、秘書が返信の文案を作ります
- **Q. iPhone のカレンダーを使っています**
  A. つなげます。まず、iPhone の「カレンダー」アプリで画面下の「カレンダー」を押し、一覧の見出しを見てください
  - 「iCloud」の予定: 当日、Apple の「App 用パスワード」を一緒に作ります（Apple ID の2段階認証が必要です）
  - 「Gmail」（Google）の予定: ②の Google カレンダーのボタンでつながります。App 用パスワードは要りません
  - 「Outlook」「Exchange」の予定: 会社の Microsoft 365 なら②の Microsoft 365 のボタンでつながります
